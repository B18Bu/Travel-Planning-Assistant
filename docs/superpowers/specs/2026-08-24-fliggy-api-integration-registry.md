## 6. 错误、限流与可靠性策略

| 场景 | 飞猪响应/错误码 | 本项目 HTTP 状态 | 用户可见文案 | 是否重试 | 依据 |
| --- | --- | ---: | --- | --- | --- |
| 参数错误 |  | 422 | 请求参数不符合要求。 | 否 |  |
| 鉴权失败 |  | 503 | 实时查询暂不可用，请稍后重试。 | 否 |  |
| 限流 |  | 503 | 实时查询暂不可用，请稍后重试。 | 待确认 |  |
| 上游 5xx |  | 503 | 实时查询暂不可用，请稍后重试。 | 待确认 |  |
| 网络或超时 |  | 503 | 实时查询暂不可用，请稍后重试。 | 待确认 |  |
| 无匹配结果 |  | 200 | 暂未找到匹配结果，请调整条件后重试。 | 否 |  |

补充确认：最大请求超时、最大重试次数、退避策略、熔断阈值、熔断时长、调用预算、并发限制和手动刷新限制。
