## 3. 车票查询接口

### 3.0 官方目录初查结果

官方目录中与本项目最相关的接口并不完全符合“面向普通用户实时检索”的目标，必须先确认应用资质与授权范围：

| 能力 | 官方目录条目 | 链接 | 初查结论 |
| --- | --- | --- | --- |
| 火车票城市编码 | `alitrip.btrip.train.city.suggest` | [API 32207](https://open.alitrip.com/docs/api.htm?apiId=32207) | 需要授权；请求包含 `user_id`、`keyword`、`corp_id`；返回城市 `code`、`name`。属于商旅城市搜索，不是车次查询。 |
| 火车站数据 | `alitrip.btrip.supplychain.train.city` | [API 53623](https://open.alitrip.com/docs/api.htm?apiId=53623) | 需要授权；请求包含 `corp_id`、`keyword`、`version`；返回车站城市编码。属于商旅数据。 |
| 火车票订单查询 | `alitrip.btrip.supplychain.train.search` | [API 53595](https://open.alitrip.com/docs/api.htm?apiId=53595) | 页面明确提示“接口已暂停维护，请对接新版接口”；是订单查询，不可作为本项目车次搜索接口。 |
| 航班列表/询价 | `alitrip.flight.service.search` | [API 61643](https://open.alitrip.com/docs/api.htm?apiId=61643) | 需要授权、聚石塔内调用；属于航班询价，使用城市三字码、行程类型、渠道名称等字段。 |
| 商旅航班列表 | `alitrip.btrip.flight.distribution.flightlist` | [API 57435](https://open.alitrip.com/docs/api.htm?apiId=57435) | 不需要授权；属于商旅机票分销询价，需 `sub_channel`，返回航班、价格、余座等字段；需确认是否对本项目主体开放。 |
| 机票城市搜索 | `alitrip.btrip.flight.city.suggest` | [API 32208](https://open.alitrip.com/docs/api.htm?apiId=32208) | 需要授权；请求包含 `user_id`、`keyword`、`corp_id`；返回城市三字码。 |

目录中的火车票类目（[火车票 API 类目](https://open.alitrip.com/docs/api_list.htm?cid=20540)）当前主要是代理商订单、出票、退票、改签和候补流程，未发现可直接用于本项目“车次列表查询”的公开条目。因此，车票功能不能按原计划直接承诺火车实时查询。

## 4. 酒店查询接口

### 4.0 官方目录初查结果

官方目录中与酒店查询最接近的是商旅酒店分销接口，而不是酒店商品维护或订单接口：

| 能力 | 官方目录条目 | 链接 | 初查结论 |
| --- | --- | --- | --- |
| 酒店静态信息 | `alitrip.btrip.hotel.distribution.search.static` | [API 56179](https://open.alitrip.com/docs/api.htm?apiId=56179) | 不需要授权；需要城市编码、分页和 `sub_channel`；返回酒店基础信息、房型、图片、设施、评分等字段。展示许可、图片版权和渠道资格仍需确认。 |
| 酒店最低价 | `alitrip.btrip.hotel.distribution.search.low.price` | [API 56180](https://open.alitrip.com/docs/api.htm?apiId=56180) | 不需要授权；入住/离店日期、城市、`sub_channel`、排序和分页为主要参数；`low_price` 单位为分；返回供应商和协议价标识。适合候选酒店价格列表，但需确认实时性和调用资格。 |
| 酒店详情报价 | `alitrip.btrip.hotel.distribution.search.detail` | [API 56181](https://open.alitrip.com/docs/api.htm?apiId=56181) | 不需要授权；需要入住/离店日期、酒店标准 ID、城市编码和 `sub_channel`；返回房型、库存价格、配额、取消政策、促销、币种等字段。它是报价详情接口，尚不能直接等同于“可订保证”。 |

| 酒店订单/预订 | `taobao.xhotel.order.*` / 分销订单接口 | [酒店在线预订 API 类目](https://open.alitrip.com/docs/api_list.htm?cid=20753) | 包含订单搜索、创建、支付和取消等交易能力；明确排除。 |

## 5. 官方公共调用配置

根据已打开的官方 API 详情页，相关接口共用淘宝开放平台公共调用参数：

| 参数 | 官方页面信息 | 项目处理 |
| --- | --- | --- |
| `method` | API 接口名称，必填 | 由后端固定映射，客户端不得传入。 |
| `app_key` | TOP 分配给应用的 AppKey，必填 | 仅从服务端密钥配置读取。 |
| `sign_method` | `hmac` 或 `md5`，必填 | 以应用授权和官方签名说明为准，禁止客户端选择。 |
| `sign` | 输入参数签名结果，必填 | 后端生成，不记录、不返回。 |
| `session` | 标记为需要授权的 API 时必传 | 需要确认本项目采用的授权主体和 session 获取方式；不可把前端会话直接当作飞猪 session。 |
| `timestamp` | `yyyy-MM-dd HH:mm:ss`，GMT+8；服务端允许最大时间误差 10 分钟 | 后端生成并校验服务器时间。 |
| `format` | 默认 XML，可选 XML/JSON | 后端固定使用 JSON，并校验响应结构。 |
| `v` | API 协议版本 `2.0` | 后端固定配置。 |
| `partner_id` | 合作伙伴身份标识，可选 | 仅在授权合同要求时配置。 |
| `simplify` | JSON 精简返回，可选 | 后端固定值，不由前端覆盖。 |

**官方正式环境地址：** 文档页面显示 HTTP `http://gw.api.taobao.com/router/rest` 与 HTTPS `https://eco.taobao.com/router/rest`。本项目只允许 HTTPS；在应用资质确认前不得启用真实调用。

**官方文档中发现的边界：** 多个“需要授权”接口依赖 `session`；部分分销搜索接口标为“不需要授权”，但仍要求 `sub_channel` 或 `corp_id`。因此“页面标注不需要授权”不等于本项目无需申请渠道资格，必须以应用管理中心和书面授权结果为准。

## 7. 错误、限流与可靠性策略

| 场景 | 飞猪响应/错误码 | 本项目 HTTP 状态 | 用户可见文案 | 是否重试 | 依据 |
| --- | --- | ---: | --- | --- | --- |
| 参数错误 |  | 422 | 请求参数不符合要求。 | 否 |  |
| 鉴权失败 |  | 503 | 实时查询暂不可用，请稍后重试。 | 否 |  |
| 限流 |  | 503 | 实时查询暂不可用，请稍后重试。 | 待确认 |  |
| 上游 5xx |  | 503 | 实时查询暂不可用，请稍后重试。 | 待确认 |  |
| 网络或超时 |  | 503 | 实时查询暂不可用，请稍后重试。 | 待确认 |  |
| 无匹配结果 |  | 200 | 暂未找到匹配结果，请调整条件后重试。 | 否 |  |
