# 智能文旅策划助手答辩 PPT 提示词设计

## 目标

编写一份可直接粘贴到 WPS AI 或讯飞智文的中文总提示词，用于生成 10–15 分钟毕业设计答辩 PPT。

## 输入依据

- `docs/答辩讲解/智能文旅策划助手-设计答辩.html`
- 当前项目的「智能文旅策划助手」主题：多 Agent 编排、强类型数据合同、文档知识库 RAG、韧性设计和安全边界。

## 已确认的视觉方向

- **背景：** B 方案。以浅暖白为主背景，低饱和青绿色作为主要强调色，暖橙仅用于页码、编号和重点提示。
- **版式：** C 方案。采用章节编号、短标题、小色条和少量信息块；保留大面积留白。
- **禁用：** 深色大面积底图、强渐变、炫光、3D 装饰、复杂纹理、无关插画、密集文字和夸张动画。

## 内容范围

整套 PPT 约 15 页，按答辩主线压缩现有 HTML：

1. 封面
2. 项目背景与一句话定位
3. 用户痛点
4. 核心难点
5. 项目目标与 MVP 边界
6. 功能模块总览
7. 技术栈与选型原则
8. 系统总体架构
9. 强类型数据合同与状态机
10. 多 Agent 编排流程
11. 文档知识库与 RAG 检索
12. 韧性与安全边界
13. 前端交互、测试与质量保障
14. 项目亮点与创新点
15. 局限、后续规划与致谢

## 内容粒度

- 每页使用 1 个核心结论、3–6 条短要点和 1 个必要的简约图形或流程。
- 「痛点」与「难点」仅使用短标签，不展开具体说明；例如「信息分散」「时间成本大」「数据源异构」「上游服务不稳定」。
- 忠实保留只读、非交易的 MVP 边界；不得宣称已接入预订、支付、实时价格、库存、评分或订单能力。
- 事实性内容强调由确定性代码与强类型数据合同保证，LLM 仅用于受控表达或 OCR 辅助。

## 验收标准

- 可整段复制至 WPS AI / 讯飞智文生成。
- 主题、章节与技术重点和答辩 HTML 保持一致。
- 生成结果为浅色、简约、易讲解的答辩材料，而不是信息堆砌的技术文档。
