# 🌍 智能文旅策划助手 — 项目开发文档

> **一句话说明**：用户在网页输入「现居地 + 目的地」或「地区名」，系统调用 AI 生成完整旅行方案，或从内置知识库检索该地区已收录的游玩方案与美食推荐。
>
> **项目形态**：前后端分离的 Web 应用
> - 前端：网页（浏览器打开即可用）
> - 后端：Python 接口服务，负责调用 AI / 检索知识库
>
> **面向读者**：技术小白 / 初次接触 Web 开发的人，文档通用、不假定你的电脑环境。
>
> **版本说明**：本文档按**版本演进**组织。四个版本按「方向」归组，后一版只在前一版基础上新增一个方向的能力，前一版能力保持不变 —— **基线 → 有据 → 可溯 → 可评**。每个版本都是独立可运行的里程碑，建议按顺序逐个实现。

---

## 一、项目概述

### 1.1 这个项目做什么

网页提供两个入口：

| 入口 | 输入 | 输出 | 所属版本 |
|------|------|------|---------|
| **① 完整规划** | 现居地 + 目的地 | AI 生成完整方案（出行 + 景点 + 美食 + 行程） | v1 |
| **② 目的地攻略** | 地区名（搜索框） | 从知识库检索该地区已收录的攻略；没有则 AI 兜底生成 | v2 |

**① 完整规划**的输出内容：

| 输出内容 | 说明 |
|---------|------|
| **最快出行方案** | 怎么去最快，耗时多久，大概多少钱 |
| **性价比最高方案** | 怎么去最划算，为什么 |
| **景点推荐** | 当地必去的景点（5 个左右，带简介） |
| **美食推荐** | 当地特色美食（5 种左右，说明哪里吃） |
| **景点游玩方案** | 按天安排的 2-3 天行程（上午/下午/晚上） |

**② 目的地攻略**的输出内容：该地区的景点推荐、美食推荐、游玩行程。来自知识库文档的内容**可溯源**（v3，标注文档名/页码），每条回答下方都有赞/踩反馈（v4，用于统计内容是否有用）。

### 1.2 版本演进总览

```
v1 基础方案 ──► v2 知识库检索 ──► v3 内容溯源 ──► v4 反馈统计
   AI 生成         有据可依          可验证           可评测
```

| 版本 | 方向 | 核心能力 | 新增关键模块 |
|------|------|---------|------------|
| **v1 基础方案** | AI 一键策划 | 现居地 + 目的地 → DeepSeek 生成完整方案 | `main.py` + `index.html`（前后端分离） |
| **v2 知识库检索** | 让回答有依据 | 搜索框入口 + Word/PDF 文档解析 + BGE/FAISS 向量检索 + AI 兜底 | `config.py`/`.env`、`parser.py`、`ingest.py`、`rag.py`、`POST /api/region` |
| **v3 内容溯源** | 让回答可验证 | 内容块携带来源元数据（文档名/页码/章节），检索结果返回 `sources` | 溯源元数据 + `sources` 字段 |
| **v4 反馈统计** | 用数据评测 | 消息卡片蓝色小字来源 + 赞/踩按钮 + SQLite 聚合统计 | `message_id`、`POST /api/feedback`、`GET /api/stats`、前端消息卡片 |

**连续性**：
- v2 在 v1 基础上新增「目的地攻略」入口，v1 的「完整规划」完全不动；
- v3 让 v2 的检索结果可溯源，用户能核对每条内容的真实出处；
- v4 让所有回答可被评价，用数据判断「知识库内容 vs AI 生成内容」哪个更受认可，从而持续优化知识库。

## 二、技术选型

| 层 | 技术 | 为什么选它 | 所属版本 |
|----|------|-----------|---------|
| **前端** | HTML + CSS + JavaScript（原生）+ marked.js | 零构建工具，浏览器打开即用；marked.js 渲染 Markdown（含表格） | v1 / v4 |
| **后端** | Python + FastAPI | 代码少、上手快、自带接口文档 | v1 |
| **AI 能力** | DeepSeek API | 便宜（约 1 元/百万 token）、国产、效果好；用于完整方案生成与兜底 | v1 / v2 |
| **文档解析** | python-docx + pymupdf + pdfplumber | 解析 Word 文本/表格、PDF 文本层/表格 | v2 |
| **图片识别** | minerU API + Qwen-VL API | 扫描/图片型 PDF 的版面切分（minerU）与文字/表格识别（Qwen-VL） | v2 |
| **嵌入检索** | sentence-transformers（BGE）+ FAISS | 本地免费向量化 + 相似度检索，无需额外 API key | v2 |
| **配置管理** | python-dotenv（.env）+ config.py | 统一管理 API key / base_url / 模型名 / 阈值等 | v2 |
| **存储统计** | SQLite（Python 内置 sqlite3） | 零额外依赖，存赞踩反馈与统计 | v4 |

> 💡 为什么「目的地攻略」用 RAG 而不是纯大模型？
> - 知识库里的攻略是**人工整理、可追溯**的权威内容，避免大模型「编造」；
> - 命中知识库时**零调用费用、响应快**；
> - 只有检索不到的地区才用大模型兜底，既保覆盖面又省成本。

## 三、版本一 · 基础方案（v1）—— AI 一键策划

### 3.1 功能与流程

用户在网页输入：现居地 = 北京，目的地 = 成都，点「生成方案」。

```
用户在网页输入：现居地=北京，目的地=成都
        │
        ▼
前端把这两个值 POST 给后端接口
        │
        ▼
后端拼装提示词，调用 DeepSeek 大模型 API
        │
        ▼
大模型生成完整方案（Markdown 文本）
        │
        ▼
后端返回给前端，前端渲染展示给用户
```

### 3.2 系统架构（v1）

```
┌─────────────────────┐         ┌─────────────────────┐         ┌──────────────┐
│      前端 index.html │         │    后端 main.py      │         │  DeepSeek    │
│                     │  POST   │                     │  POST   │  大模型 API  │
│  输入框 + 按钮       │ ──────→ │  FastAPI 服务        │ ──────→ │              │
│  展示结果            │ ←────── │  拼提示词/调接口      │ ←────── │  生成方案    │
│  (浏览器)           │   JSON  │  (Python)           │  文本   │  (云端)      │
└─────────────────────┘         └─────────────────────┘         └──────────────┘
       浏览器 localhost:8000           localhost:8000
```

**关键点**：前端和后端是**两个独立的程序**，通过 HTTP 接口通信。前端负责「长得好看 + 收集输入 + 展示结果」，后端负责「调用 AI + 返回数据」。

### 3.4 后端代码（v1 · main.py）

```python
# 智能文旅策划助手 — 后端服务（v1：完整规划，AI 一键生成）
import os
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field
import httpx

app = FastAPI(title="智能文旅策划助手", version="1.0.0")

# 允许前端跨域访问（前端用浏览器打开时必需）
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

DEEPSEEK_API_KEY = os.getenv("DEEPSEEK_API_KEY", "")
DEEPSEEK_URL = "https://api.deepseek.com/chat/completions"
DEEPSEEK_MODEL = os.getenv("DEEPSEEK_MODEL", "deepseek-chat")


class PlanRequest(BaseModel):
    origin: str = Field(..., description="现居地，例如：北京")
    destination: str = Field(..., description="目的地，例如：成都")


def build_prompt(origin: str, destination: str) -> str:
    # 把用户输入拼装成大模型能理解的提示词
    lines = []
    lines.append(f"你是一位专业的文旅策划师。请为用户规划从「{origin}」前往「{destination}」的完整旅行方案。")
    lines.append("")
    lines.append("请按以下结构输出（使用 Markdown 格式，内容详实、实用）：")
    lines.append("")
    lines.append("## 一、出行方案")
    lines.append("### 1. 最快方案")
    lines.append("（说明推荐的交通方式、大致耗时、参考票价区间）")
    lines.append("### 2. 性价比最高方案")
    lines.append("（说明推荐的交通方式、大致耗时、参考票价区间、为什么划算）")
    lines.append("")
    lines.append("## 二、必游景点推荐")
    lines.append("（推荐 5 个左右必去景点，每个景点用 1-2 句话说明亮点）")
    lines.append("")
    lines.append("## 三、美食推荐")
    lines.append("（推荐 5 种左右当地特色美食，说明是什么、哪里吃）")
    lines.append("")
    lines.append("## 四、景点游玩方案")
    lines.append("（按天数安排一个 2-3 天的行程，每天列出上午/下午/晚上的安排）")
    lines.append("")
    lines.append("请注意：")
    lines.append("1. 交通耗时和票价是估算值，仅供规划参考")
    lines.append("2. 景点和美食要符合当地实际情况")
    lines.append("3. 行程安排要合理，避免路线重复")
    return "\n".join(lines)


@app.post("/api/plan")
async def create_plan(req: PlanRequest):
    # 核心接口：接收现居地和目的地，返回完整方案
    if not DEEPSEEK_API_KEY:
        raise HTTPException(status_code=500, detail="未配置 DEEPSEEK_API_KEY 环境变量")
    try:
        async with httpx.AsyncClient(timeout=120) as client:
            resp = await client.post(
                DEEPSEEK_URL,
                json={
                    "model": DEEPSEEK_MODEL,
                    "messages": [
                        {"role": "user", "content": build_prompt(req.origin, req.destination)}
                    ],
                    "temperature": 0.7,
                },
                headers={"Authorization": f"Bearer {DEEPSEEK_API_KEY}"},
            )
            resp.raise_for_status()
            data = resp.json()
            content = data["choices"][0]["message"]["content"]
        return {
            "origin": req.origin,
            "destination": req.destination,
            "plan": content,
        }
    except Exception as e:
        raise HTTPException(status_code=500, detail=f"调用 AI 服务失败：{e}")


@app.get("/api/health")
async def health():
    return {"status": "ok"}


if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 四、版本二 · 知识库检索（v2）—— 让回答有据可依

### 4.1 目标与新增能力

v1 的完整方案完全依赖大模型，景点/美食可能「编造」且不可追溯。v2 新增第二个入口「**目的地攻略**」：输入地区名，从**内置知识库**检索该地区已收录的游玩方案/美食推荐；检索不到才用大模型兜底。

新增六件事：
1. **搜索框入口**：前端增加 Tab「目的地攻略」；
2. **文档解析**：知识库由 Word/PDF 文档组成，解析出文本与**表格**；
3. **向量索引**：解析结果切块 → BGE 本地嵌入 → FAISS 索引；
4. **扩写预测**：拿到用户 query 后先用大模型扩写成多个角度，让检索/生成更丰富（见 4.7）；
5. **检索与兜底**：`/api/region` 多路检索命中返回知识库内容，未命中 DeepSeek 兜底；
6. **配置管理**：所有 API key / base_url / 模型名用 `.env` + `config.py` 统一管理。

### 4.2 知识库：Word/PDF 文档

把每个地区的攻略整理成 Word 或 PDF 文档，放入 `knowledge/documents/`。**建议一个地区一个文档**，文档内用标题分节（如「景点推荐」「美食推荐」「游玩行程」），表格（如菜品价格表、景点门票表）会被原样提取。

```
knowledge/documents/
├── 成都.docx          # 成都攻略
├── 三亚.pdf           # 三亚攻略（含扫描页时走视觉识别）
└── ...
```

### 4.3 配置管理（config.py + .env）

v2 起涉及多个服务（DeepSeek / Qwen-VL / MinerU / 嵌入模型），密钥和地址不能散落在代码里。用 `.env` 存密钥、`config.py` 统一读取。

**新增依赖**：`python-dotenv`

**config.py**：

```python
# config.py — 统一读取 .env 配置（所有密钥 / 地址 / 模型名 / 参数都从这里来）
import os
from dotenv import load_dotenv

load_dotenv()  # 读取项目根目录的 .env 文件


# ===== DeepSeek（完整方案生成 + 兜底） =====
DEEPSEEK_API_KEY = os.getenv("DEEPSEEK_API_KEY", "")
DEEPSEEK_BASE_URL = os.getenv("DEEPSEEK_BASE_URL", "https://api.deepseek.com")
DEEPSEEK_MODEL = os.getenv("DEEPSEEK_MODEL", "deepseek-chat")

# ===== Qwen-VL（PDF 扫描页/图片识别） =====
QWEN_API_KEY = os.getenv("QWEN_API_KEY", "")
QWEN_BASE_URL = os.getenv("QWEN_BASE_URL", "https://dashscope.aliyuncs.com/compatible-mode/v1")
QWEN_VL_MODEL = os.getenv("QWEN_VL_MODEL", "qwen-vl-max")

# ===== MinerU（PDF 版面切分） =====
MINERU_API_KEY = os.getenv("MINERU_API_KEY", "")
MINERU_BASE_URL = os.getenv("MINERU_BASE_URL", "")

# ===== 嵌入模型（本地 sentence-transformers） =====
EMBEDDING_MODEL = os.getenv("EMBEDDING_MODEL", "BAAI/bge-small-zh-v1.5")

# ===== 检索参数 =====
SIMILARITY_THRESHOLD = float(os.getenv("SIMILARITY_THRESHOLD", "0.5"))  # 相似度低于它视为未命中
TOP_K = int(os.getenv("TOP_K", "5"))                                    # 返回最相似的块数

# ===== 路径 =====
DOCS_DIR = os.getenv("DOCS_DIR", "knowledge/documents")   # 原始 Word/PDF 文档
INDEX_PATH = os.getenv("INDEX_PATH", "index/faiss.bin")   # FAISS 索引
DB_PATH = os.getenv("DB_PATH", "data/app.db")             # SQLite（v4 反馈统计用）
```

### 4.4 文档解析管道（parser.py）

| 文档类型 | 解析方式 |
|---------|---------|
| **Word（.docx）** | python-docx：按标题分节，提取正文段落 + **表格**（转 Markdown 表格） |
| **PDF（有文本层）** | pdfplumber：直接提取文字 + `extract_tables()` 提取表格 |
| **PDF（扫描/图片页）** | 渲染成 PNG → **minerU API 切分版面**（定位文本区/表格区）→ **Qwen-VL API 识别**文字与表格 → 组装 Markdown |

```python
# parser.py — 把 Word/PDF 文档解析成 Markdown 文本块（v2 版）
import os


def parse_docx(path: str) -> list[str]:
    """解析 Word：标题分节 + 正文 + 表格 → 返回 Markdown 文本块列表"""
    from docx import Document
    from docx.table import Table
    from docx.text.paragraph import Paragraph

    doc = Document(path)
    sections, lines, section = [], [], "正文"

    def flush():
        if lines:
            text = "\n".join(lines).strip()
            if text:
                sections.append(f"## {section}\n\n{text}")
            lines.clear()

    # 按文档顺序遍历段落与表格（保持原文顺序）
    for child in doc.element.body.iterchildren():
        tag = child.tag
        if tag.endswith("}p"):                       # 段落
            para = Paragraph(child, doc)
            text = para.text.strip()
            if not text:
                continue
            if para.style.name.startswith(("Heading", "标题")):
                flush(); section = text; continue   # 标题开启新一节
            lines.append(text)
        elif tag.endswith("}tbl"):                   # 表格
            lines.append(table_to_markdown(Table(child, doc)))
    flush()
    return sections


def table_to_markdown(table) -> str:
    """Word / pdfplumber 表格对象 → Markdown 表格字符串"""
    rows = [[c.text.replace("\n", " ").strip() for c in r.cells] for r in table.rows]
    return rows_to_markdown(rows)


def rows_to_markdown(rows) -> str:
    """通用：二维数组 → Markdown 表格（含表头分隔行）"""
    rows = [r for r in rows if any(c for c in r)]   # 去掉全空行
    if not rows:
        return ""
    width = max(len(r) for r in rows)
    rows = [r + [""] * (width - len(r)) for r in rows]
    out = ["| " + " | ".join(rows[0]) + " |",
           "| " + " | ".join(["---"] * width) + " |"]
    out += ["| " + " | ".join(r) + " |" for r in rows[1:]]
    return "\n".join(out)


def parse_pdf(path: str) -> list[str]:
    """解析 PDF：有文本层的页直接提取；无文本层的页渲染成图片走视觉识别"""
    import pdfplumber
    blocks = []
    with pdfplumber.open(path) as pdf:
        for page_no, page in enumerate(pdf.pages, start=1):
            text = page.extract_text() or ""
            tables = page.extract_tables() or []
            if text.strip() or tables:
                # 有文本层：直接提取文字 + 表格
                parts = [text] + [rows_to_markdown(t) for t in tables]
                content = "\n\n".join(p for p in parts if p.strip())
            else:
                # 无文本层（扫描/图片页）：走视觉识别
                content = recognize_pdf_image(path, page_no)
            if content:
                blocks.append(f"## 第 {page_no} 页\n\n{content}")
    return blocks


def recognize_pdf_image(path: str, page_no: int) -> str:
    """渲染页面为 PNG → minerU 切分版面 → Qwen-VL 识别文字/表格"""
    import fitz, base64
    doc = fitz.open(path)
    pix = doc[page_no - 1].get_pixmap(dpi=150)
    img_b64 = base64.b64encode(pix.tobytes("png")).decode()
    doc.close()
    regions = call_mineru_segment(img_b64)                 # ① 切分版面
    parts = [call_qwen_vl_recognize(img_b64, r) for r in regions]  # ② 逐区域识别
    return "\n\n".join(p for p in parts if p)


def call_mineru_segment(img_b64: str):
    """调用 minerU API 做版面切分，返回区域列表。★按你部署的 minerU 接口调整。"""
    # 示意：POST {MINERU_BASE_URL}/segment
    # resp = httpx.post(MINERU_BASE_URL + "/segment",

    #     json={"image": img_b64})
    # return resp.json()["regions"]     # 如 [{"type":"text"},{"type":"table"}]
    return [{"type": "whole_page"}]     # 简化：整页作为一个区域


def call_qwen_vl_recognize(img_b64: str, region) -> str:
    """调用 Qwen-VL 识别图片，返回 Markdown 文字/表格（DashScope OpenAI 兼容接口）"""

        json={
            "model": QWEN_VL_MODEL,
            "messages": [{
                "role": "user",
                "content": [
                    {"type": "image_url",
                     "image_url": {"url": f"data:image/png;base64,{img_b64}"}},
                    {"type": "text",
                     "text": "请识别这张图片中的全部文字和表格，输出为 Markdown（表格用 | 分隔）。"},
```

### 4.5 索引构建（ingest.py）

离线脚本：解析全部文档 → 切块 → BGE 嵌入 → 存入 FAISS 索引。**建索引是离线的、手动跑的**，跑完后 Web 服务启动只加载现成索引，不会在用户请求时调用识别 API。

```python
# ingest.py — 离线脚本：解析知识库文档 → 切块 → 嵌入 → 建 FAISS 索引
# 用法: python ingest.py
import os, glob, pickle
from config import DOCS_DIR, INDEX_PATH, EMBEDDING_MODEL
from parser import parse_docx, parse_pdf


def split_text(text: str, max_len: int = 800) -> list[str]:
    """一个内容块太长时按空行切小，保证检索粒度"""
    if len(text) <= max_len:
        return [text]
    parts, buf = [], ""
    for para in text.split("\n\n"):
        if len(buf) + len(para) < max_len:
            buf = f"{buf}\n\n{para}" if buf else para
        else:
            parts.append(buf); buf = para
    if buf:
        parts.append(buf)
    return parts


def main():
    from sentence_transformers import SentenceTransformer
    import faiss
    import numpy as np

    print("📄 加载嵌入模型：", EMBEDDING_MODEL)
    model = SentenceTransformer(EMBEDDING_MODEL)   # 首次使用自动下载模型

    chunks = []
    for ext, parser in (("*.docx", parse_docx), ("*.pdf", parse_pdf)):
        for path in glob.glob(os.path.join(DOCS_DIR, ext)):
            print("→ 解析：", os.path.basename(path))
            chunks.extend(parser(path))

    if not chunks:
        print("⚠️ 知识库为空，请先往 knowledge/documents/ 放入 Word/PDF 文档")
        return

    texts = []
    for c in chunks:
        texts.extend(split_text(c))

    print(f"🔢 共 {len(texts)} 个内容块，开始向量化...")
    vectors = model.encode(texts, normalize_embeddings=True)   # 归一化后可用内积≈余弦

    dim = vectors.shape[1]
    index = faiss.IndexFlatIP(dim)          # 内积索引（向量已归一化）
    index.add(vectors)

    os.makedirs(os.path.dirname(INDEX_PATH), exist_ok=True)
    faiss.write_index(index, INDEX_PATH)
    with open(INDEX_PATH + ".texts.pkl", "wb") as f:   # 向量 id ↔ 文本内容
        pickle.dump(texts, f)

    print(f"✅ 完成：{len(texts)} 个内容块 → {INDEX_PATH}")


if __name__ == "__main__":
    main()
```

```python
# rag.py — 加载 FAISS 索引，检索并返回命中的内容（v2 版）
import os, pickle
import numpy as np
from config import INDEX_PATH, EMBEDDING_MODEL, SIMILARITY_THRESHOLD, TOP_K


class Retriever:
    def __init__(self):
        self.model = None     # 惰性加载：首次检索时才加载嵌入模型
        self.index = None
        self.texts = []
        self.load()

    def load(self):
        import faiss
        if not os.path.exists(INDEX_PATH):
            return               # 还没建索引，此时检索永远未命中
        self.index = faiss.read_index(INDEX_PATH)
        with open(INDEX_PATH + ".texts.pkl", "rb") as f:
            self.texts = pickle.load(f)

    def _get_model(self):
        if self.model is None:
            from sentence_transformers import SentenceTransformer
            self.model = SentenceTransformer(EMBEDDING_MODEL)
        return self.model

    def search(self, query: str):
        """返回 (命中的文本列表, 是否命中)"""
        if self.index is None or not self.texts:
            return [], False
        vec = self._get_model().encode([query], normalize_embeddings=True)
        scores, ids = self.index.search(vec, k=min(TOP_K, len(self.texts)))
        hits = []
        for score, idx in zip(scores[0], ids[0]):
            if idx < 0 or score < SIMILARITY_THRESHOLD:
                continue          # 相似度低于阈值 → 未命中
            hits.append(self.texts[idx])
        return hits, len(hits) > 0
```

### 4.7 扩写预测：让检索与生成更丰富

用户 query 往往很短（如「成都」），直接检索召回内容单一、生成方案简单，难以满足真实需求。v2 在拿到 query 后、进入检索/生成**之前**，加一步**扩写预测**：用大模型把需求展开成多个角度，再检索/生成。

```
用户 query「成都」
      │  query_expand（DeepSeek 扩写，temperature 0.3）
      ▼
  [成都 必游景点] [成都 特色美食 老字号] [成都 2-3 天行程] [成都 亲子游] …
      │  search_multi（多路检索 → 按内容去重合并）
      ▼
  返回更丰富的攻略（景点 / 美食 / 行程多角度覆盖）
```

- **目的地攻略**：query → 扩写成 4-6 个角度的检索词 → 多路检索合并，召回覆盖景点/美食/行程等多方面；
- **完整规划**：query → 扩写成规划要点清单（出行方式/景点/美食/行程天数/预算/季节/同行人群/文化提示）→ 注入提示词 → 生成的方案更详尽；
- **兜底保护**：扩写失败或超时时自动回退到原 query，不影响主流程。

```python
def search_multi(self, queries: list[str]) -> tuple[list, bool]:
    """对每个扩展 query 分别检索，按内容去重后合并，再按相似度排序"""
    merged = {}
    for q in queries:
        hits, _ = self.search(q)
        for h in hits:
            merged.setdefault(h["text"], h)   # 同内容只保留一条
    hits = sorted(merged.values(), key=lambda x: x["score"], reverse=True)
    return hits, len(hits) > 0
```

> - `call_deepseek` 增加可选的 `temperature` 参数（默认 0.7，扩写时用 0.3 更稳定），完整代码见 8.7；

```python
@app.get("/api/stats")
async def stats():
    conn = sqlite3.connect(DB_PATH); conn.row_factory = sqlite3.Row

    def agg(by):
        rows = conn.execute(f"""
            SELECT m.{by} AS key,
                   SUM(CASE WHEN f.rating='like' THEN 1 ELSE 0 END) AS likes,
                   SUM(CASE WHEN f.rating='dislike' THEN 1 ELSE 0 END) AS dislikes,
                   COUNT(*) AS total
            FROM feedback f JOIN messages m ON f.message_id = m.message_id
            GROUP BY m.{by} ORDER BY total DESC
        """).fetchall()
        return [dict(r) for r in rows]

    # 按来源文档聚合：拆解 messages.sources 里的 doc_name
    from collections import defaultdict
    by_doc = defaultdict(lambda: {"likes": 0, "dislikes": 0, "total": 0})
    rows = conn.execute("SELECT f.rating, m.sources FROM feedback f JOIN messages m ON f.message_id=m.message_id").fetchall()
    for rating, sources_json in rows:
        try:
            sources = json.loads(sources_json or "[]")
        except json.JSONDecodeError:
            sources = []
        for s in sources:
            by_doc[s.get("doc_name", "未知")][rating if rating == "like" else "dislikes"] += 1
            by_doc[s.get("doc_name", "未知")]["total"] += 1

    conn.close()
    return {
        "by_source_type": agg("source_type"),
        "by_region": agg("region"),
        "by_doc": [{"key": k, **v} for k, v in by_doc.items()],
```

### 8.4 parser.py（含溯源元数据）

```python
# parser.py — 把 Word/PDF 文档解析成内容块，每个块携带来源元数据（可溯源）
import os
from dataclasses import dataclass


@dataclass
class Chunk:
    text: str          # 内容（含 Markdown 表格）
    doc_name: str      # 来源文档名，如 成都.docx
    page: str          # 页码：PDF 精确页码；Word 用章节定位
    section: str = ""  # 所属小节，如 美食推荐


def parse_docx(path: str) -> list[Chunk]:
    """解析 Word：标题分节 + 正文 + 表格 → 内容块（含来源）"""
    from docx import Document
    from docx.table import Table
    from docx.text.paragraph import Paragraph

    doc = Document(path)
    chunks, lines, section = [], [], "正文"

    def flush():
        if lines:
            text = "\n".join(lines).strip()
            if text:
                chunks.append(Chunk(
                    text=text, doc_name=os.path.basename(path),
                    page=f"{section} 章节", section=section,
                ))
            lines.clear()

    for child in doc.element.body.iterchildren():
        tag = child.tag
        if tag.endswith("}p"):
            para = Paragraph(child, doc)
            text = para.text.strip()
            if not text:
                continue
            if para.style.name.startswith(("Heading", "标题")):
                flush(); section = text; continue
            lines.append(text)
        elif tag.endswith("}tbl"):
            lines.append(table_to_markdown(Table(child, doc)))
    flush()
    return chunks


def table_to_markdown(table) -> str:
    """Word / pdfplumber 表格对象 → Markdown 表格字符串"""
    rows = [[c.text.replace("\n", " ").strip() for c in r.cells] for r in table.rows]
    return rows_to_markdown(rows)


def rows_to_markdown(rows) -> str:
    """通用：二维数组 → Markdown 表格"""
    rows = [r for r in rows if any(c for c in r)]
    if not rows:
        return ""
    width = max(len(r) for r in rows)
    rows = [r + [""] * (width - len(r)) for r in rows]
    out = ["| " + " | ".join(rows[0]) + " |",
           "| " + " | ".join(["---"] * width) + " |"]
    out += ["| " + " | ".join(r) + " |" for r in rows[1:]]
    return "\n".join(out)


def parse_pdf(path: str) -> list[Chunk]:
    """解析 PDF：有文本层直接提取；扫描页渲染成图片走视觉识别"""
    import pdfplumber
    doc_name = os.path.basename(path)
    chunks = []
    with pdfplumber.open(path) as pdf:
        for page_no, page in enumerate(pdf.pages, start=1):
            text = page.extract_text() or ""
            tables = page.extract_tables() or []
            if text.strip() or tables:
                parts = [text] + [rows_to_markdown(t) for t in tables]
                content = "\n\n".join(p for p in parts if p.strip())
            else:
                content = recognize_pdf_image(path, page_no)   # 扫描/图片页
            if content.strip():
                chunks.append(Chunk(text=content, doc_name=doc_name,
                                    page=f"第 {page_no} 页", section="PDF"))
    return chunks


def recognize_pdf_image(path: str, page_no: int) -> str:
    """渲染页面为 PNG → minerU 切分版面 → Qwen-VL 识别文字/表格"""
    import fitz, base64
    doc = fitz.open(path)
    pix = doc[page_no - 1].get_pixmap(dpi=150)
    img_b64 = base64.b64encode(pix.tobytes("png")).decode()
    doc.close()
```

```python
# ingest.py — 离线脚本：解析知识库 → 切块 → 嵌入 → 建 FAISS 索引 + 来源元数据
# 用法: python ingest.py
import os, glob, pickle
from config import DOCS_DIR, INDEX_PATH, get_config
from parser import parse_docx, parse_pdf, Chunk


def split_chunks(chunk: Chunk, max_len: int = 800) -> list[Chunk]:
    """一个来源块太长时切小，每个小块继承来源元数据"""
    if len(chunk.text) <= max_len:
        return [chunk]
    parts, buf = [], ""
    for para in chunk.text.split("\n\n"):
        if len(buf) + len(para) < max_len:
            buf = f"{buf}\n\n{para}" if buf else para
        else:
            parts.append(Chunk(text=buf, doc_name=chunk.doc_name,
                               page=chunk.page, section=chunk.section))
            buf = para
    if buf:
        parts.append(Chunk(text=buf, doc_name=chunk.doc_name,
                           page=chunk.page, section=chunk.section))
    return parts


def main():
    from sentence_transformers import SentenceTransformer
    import faiss
    import numpy as np

    print("📄 加载嵌入模型：", get_config()["EMBEDDING_MODEL"])
    model = SentenceTransformer(get_config()["EMBEDDING_MODEL"])   # 首次自动下载

    all_chunks: list[Chunk] = []
    for ext, parser in (("*.docx", parse_docx), ("*.pdf", parse_pdf)):
        for path in glob.glob(os.path.join(DOCS_DIR, ext)):
            print("→ 解析：", os.path.basename(path))
            for c in parser(path):
                all_chunks.extend(split_chunks(c))

    if not all_chunks:
        print("⚠️ 知识库为空，请先往 knowledge/documents/ 放入 Word/PDF 文档")
        return

    print(f"🔢 共 {len(all_chunks)} 个内容块，开始向量化...")
    vectors = model.encode([c.text for c in all_chunks], normalize_embeddings=True)

    index = faiss.IndexFlatIP(vectors.shape[1])
    index.add(vectors)

    os.makedirs(os.path.dirname(INDEX_PATH), exist_ok=True)
    faiss.write_index(index, INDEX_PATH)

    # 元数据映射：向量 id ↔ 来源（与索引一一对应）
    meta = [{"doc_name": c.doc_name, "page": c.page, "section": c.section, "text": c.text}
            for c in all_chunks]
    with open(INDEX_PATH + ".meta.pkl", "wb") as f:
        pickle.dump(meta, f)

    print(f"✅ 完成：{len(all_chunks)} 个内容块 → {INDEX_PATH}（含来源元数据）")


if __name__ == "__main__":
    main()
```

```python
# rag.py — 加载 FAISS 索引，检索并返回「内容 + 来源元数据」
import os, pickle
import numpy as np
from config import INDEX_PATH, get_config


class Retriever:
    def __init__(self):
        self.model = None
        self.index = None
        self.meta = []            # 向量 id ↔ 来源元数据
        self.load()

    def load(self):
        import faiss
        if not os.path.exists(INDEX_PATH):
            return                # 还没建索引，检索永远未命中
        self.index = faiss.read_index(INDEX_PATH)
        with open(INDEX_PATH + ".meta.pkl", "rb") as f:
            self.meta = pickle.load(f)

    def _get_model(self):
        if self.model is None:
            from sentence_transformers import SentenceTransformer
            self.model = SentenceTransformer(get_config()["EMBEDDING_MODEL"])
        return self.model

    def search(self, query: str):
        """返回 (命中列表, 是否命中)。命中元素：{text, doc_name, page, section, score}"""
        if self.index is None or not self.meta:
            return [], False
        cfg = get_config()   # 每次检索读取当前生效配置（设置面板优先）
        vec = self._get_model().encode([query], normalize_embeddings=True)
        scores, ids = self.index.search(vec, k=min(cfg["TOP_K"], len(self.meta)))
        hits = []
        for score, idx in zip(scores[0], ids[0]):
            if idx < 0 or score < cfg["SIMILARITY_THRESHOLD"]:
                continue          # 相似度低于阈值 → 未命中
            hits.append({"score": float(score), **self.meta[idx]})
        return hits, len(hits) > 0

    def search_multi(self, queries: list[str]) -> tuple[list, bool]:
        """多路检索：对每个扩展 query 分别检索，按内容去重后合并，再按相似度排序"""
        merged = {}
        for q in queries:
            hits, _ = self.search(q)
            for h in hits:
                merged.setdefault(h["text"], h)   # 同内容只保留一条
        hits = sorted(merged.values(), key=lambda x: x["score"], reverse=True)
        return hits, len(hits) > 0


def collect_sources(hits) -> list[dict]:
    """去重收集来源清单：文档名 + 页码 + 小节"""
    seen, sources = set(), []
    for h in hits:
        key = (h["doc_name"], h["page"], h["section"])
        if key in seen:
            continue
        seen.add(key)
        sources.append({"doc_name": h["doc_name"], "page": h["page"], "section": h["section"]})
    return sources


def assemble_plan(hits) -> str:
    """把命中的内容块拼成攻略 Markdown（按来源文档分组）"""
    by_doc = {}
    for h in hits:
        by_doc.setdefault(h["doc_name"], []).append(h)
    sections = []
    for doc, hs in by_doc.items():
        parts = [h["text"] for h in hs]
        sections.append(f"### 📄 《{doc}》\n\n" + "\n\n".join(parts))
    return "\n\n".join(sections)
```

```python
    # v4 能力：按来源类型 / 地区 / 来源文档聚合统计
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row

    def agg(by):
        rows = conn.execute(f"""
            SELECT m.{by} AS key,
                   SUM(CASE WHEN f.rating='like' THEN 1 ELSE 0 END) AS likes,
                   SUM(CASE WHEN f.rating='dislike' THEN 1 ELSE 0 END) AS dislikes,
                   COUNT(*) AS total
            FROM feedback f JOIN messages m ON f.message_id = m.message_id
            GROUP BY m.{by} ORDER BY total DESC
        """).fetchall()
        return [dict(r) for r in rows]

    from collections import defaultdict
    by_doc = defaultdict(lambda: {"likes": 0, "dislikes": 0, "total": 0})
    rows = conn.execute(
        "SELECT f.rating, m.sources FROM feedback f JOIN messages m ON f.message_id = m.message_id"
    ).fetchall()
    for rating, sources_json in rows:
        try:
            sources = json.loads(sources_json or "[]")
        except json.JSONDecodeError:
            sources = []
        for s in sources:
            doc = s.get("doc_name", "未知")
            by_doc[doc]["total"] += 1
            if rating == "like":
                by_doc[doc]["likes"] += 1
            else:
                by_doc[doc]["dislikes"] += 1

    conn.close()
    return {
        "by_source_type": agg("source_type"),
        "by_region": agg("region"),
        "by_doc": [{"key": k, **v} for k, v in by_doc.items()],
    }
```

```html
function createTask(type, body, title) {
  const id = 't' + (++seq);
  const task = { id, type, body, title, isAi: type === 'plan', status: 'pending', vote: null, html: null };
  tasks.push(task);
  renderNav();

async function runTask(task) {
  const url = task.type === 'region' ? API_REGION : API_PLAN;
  const steps = ['理解需求，扩写预测', '多路检索 / 生成规划要点', '组装完整方案'];
  let step = 0;
  const timer = setInterval(() => {
    step++;
    if (currentId === task.id) {
      const el = document.querySelector('#view-task .proc-step[data-step="' + step + '"]');
      if (el) el.classList.add('active');
    }
  }, 500);
  try {
    const resp = await fetch(url, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(task.body) });
    if (!resp.ok) { const d = await resp.json().catch(() => ({})); throw new Error(d.detail || '请求失败'); }
    const data = await resp.json();
    clearInterval(timer);
    task.status = 'done';
    task.html = cardShell(data);
    renderNav();
    if (currentId === task.id) document.getElementById('view-task').innerHTML = task.html;
  } catch (e) {
    clearInterval(timer);
    task.status = 'done';
    task.html = '<div class="message"><div class="msg-body">❌ 出错了：' + e.message + '</div></div>';
    renderNav();
    if (currentId === task.id) document.getElementById('view-task').innerHTML = task.html;
  }
}

async function loadStats() {
  try {
    const resp = await fetch(API_STATS);
    const s = await resp.json();
    const kb = (s.by_source_type || []).find(x => x.key === 'knowledge');
    const llm = (s.by_source_type || []).find(x => x.key === 'llm');
    const total = (s.by_source_type || []).reduce((a, x) => a + (x.total || 0), 0);
    const rate = a => (a && a.total) ? Math.round(a.likes / a.total * 100) : 0;

    setNum('stat-total', total, '');
    setNum('stat-kb', rate(kb), '%');
    setNum('stat-llm', rate(llm), '%');
    setBar('bar-kb', rate(kb), rate(kb) + '% · ' + (kb ? kb.likes : 0) + '👍 / ' + (kb ? kb.dislikes : 0) + '👎');
    setBar('bar-llm', rate(llm), rate(llm) + '% · ' + (llm ? llm.likes : 0) + '👍 / ' + (llm ? llm.dislikes : 0) + '👎');
    document.getElementById('tbl-region').innerHTML = rowsHtml(s.by_region || []);
    document.getElementById('tbl-doc').innerHTML = rowsHtml(s.by_doc || []);
    animateStats();
  } catch (e) {
    ['stat-total', 'stat-kb', 'stat-llm'].forEach(id => document.getElementById(id).textContent = '—');
  }
}
function setNum(id, val, suffix) {
  const el = document.getElementById(id);
  el.dataset.target = val; el.dataset.suffix = suffix || '';
}
function setBar(id, w, label) {
  document.getElementById(id).style.width = w + '%';
  document.getElementById(id + '-val').textContent = label;
}
function rowsHtml(rows) {
  if (!rows.length) return '<tr><td colspan="5" class="num-mid">暂无数据</td></tr>';
  return rows.map(r => {
    const rate = r.total ? Math.round(r.likes / r.total * 100) : 0;
    const cls = rate >= 75 ? 'num-good' : rate >= 50 ? 'num-mid' : 'num-bad';
    return '<tr><td>' + (r.key || '未知') + '</td><td>' + (r.likes || 0) + '</td><td>' + (r.dislikes || 0) + '</td><td>' + (r.total || 0) + '</td><td class="' + cls + '">' + rate + '%</td></tr>';
  }).join('');
}
function animateStats() {
  document.querySelectorAll('.stat-num[data-target]').forEach(el => {
    const target = parseFloat(el.dataset.target);
    const suffix = el.dataset.suffix || '';
    const start = performance.now(), dur = 900;
    function tick(t) {
      const p = Math.min((t - start) / dur, 1);
      el.textContent = Math.round(target * (1 - Math.pow(1 - p, 3))) + suffix;
      if (p < 1) requestAnimationFrame(tick);
    }
    requestAnimationFrame(tick);
  });
}
```

## 九、运行步骤

### 9.1 准备 Python 环境

Windows / macOS / Linux 通用：安装 Python 3.11+（https://www.python.org/downloads/ ，安装时勾选 "Add to PATH"）。

### 9.2 创建项目文件夹

```bash
mkdir travel-assistant
cd travel-assistant
```

把第八节的代码文件放进文件夹：`main.py`、`index.html`、`config.py`、`parser.py`、`ingest.py`、`rag.py`、`requirements.txt`。把 `.env.example` 复制为 `.env`。

### 9.3 安装依赖

```bash
pip install -r requirements.txt
```

### 9.4 配置 .env

编辑 `.env`，填入真实密钥：

- `DEEPSEEK_API_KEY` **必填**（https://platform.deepseek.com/api_keys 获取）
- `QWEN_API_KEY` / `MINERU_API_KEY`：有扫描/图片 PDF 才需要

> 也可以在前端左下角「⚙️ 设置」里配置，**优先于 `.env`**（保存到 `data/config_overrides.json`）。

### 9.5 放入知识库文档

把 Word/PDF 攻略文档放进 `knowledge/documents/`（没有该目录就新建），**一个地区一个文档**。

### 9.6 构建知识库索引（离线）

```bash
python ingest.py
```

首次运行会下载 BGE 嵌入模型（约 100MB），之后看到 `✅ 完成：N 个内容块 → index/faiss.bin` 即成功。

> ⚠️ 每次**新增/修改** knowledge 里的文档后，都要重新运行 `python ingest.py` 重建索引。

### 9.7 启动后端

```bash
python main.py
```

看到 `Uvicorn running on http://0.0.0.0:8000` 即成功。验证：浏览器访问 http://localhost:8000/api/health 返回 `{"status":"ok"}`；接口文档 http://localhost:8000/docs 。

### 9.8 打开前端

双击 `index.html`，浏览器打开网页：

- 「完整规划」：填现居地 + 目的地 → 生成方案
- 「目的地攻略」：输入地区名 → 查攻略（命中显示蓝色小字来源；未命中显示 AI 生成）
- 每条回答下方可点赞/踩，数据可在 `/api/stats` 查看

> ⚠️ 顺序很重要：**先启动后端 → 再打开前端**。

## 十一、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 前端点了没反应 | 后端没启动 | 先运行 `python main.py` |
| 报"未配置 DEEPSEEK_API_KEY" | 没配置 .env | 按 9.4 配置 |
| 搜「XX地区」永远提示 AI 生成 | 知识库没收录该地区，或相似度低于阈值 | ① 放该地区文档后重跑 `ingest.py`；② 调低 `SIMILARITY_THRESHOLD`（如 0.4） |
| 启动后检索不到任何内容 | 没建索引 | 运行 `python ingest.py` |
| 首次建索引很慢/卡住 | 在下载嵌入模型 | 等 1-5 分钟，属正常；模型只需下载一次 |
| 返回的表格是乱码 | 前端没用 marked.js 渲染 | 确认 index.html 引入 marked.js |
| Word 来源显示"XX 章节"而非页码 | python-docx 无原生页码 | 属正常设计，Word 按章节溯源 |
| 报 MinerU / Qwen-VL 相关错误 | 扫描 PDF 但没配密钥 | 有扫描页才需要；纯文本 PDF 不需要 |
| 响应比 v1 慢了一点 | 多了一步扩写预测（+多路检索） | 属正常，扩写是短调用；可把 `query_expand` 角度调少，或对热门地区缓存结果 |
| 在「设置」里填了 key 不生效 | 没点「保存」，或覆盖文件写失败 | 保存后检查 `data/config_overrides.json`；优先级为 设置 > .env |
| 端口被占用 | 8000 端口被占用 | 改 main.py 里的 port |
| 赞/踩点了没反应 | 前端没连上 /api/feedback | 确认后端已启动且版本为 v4 |
