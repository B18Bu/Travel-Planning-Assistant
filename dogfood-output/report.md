### 3.2 发现的问题

**#1 [已修复] 省份级查询无城市隔离**

- 复现：查询「云南美食」→ 返回 海南三亚（页 46 美食）、贵州（页 2 酸汤鱼）、云南（页 3）混合内容；「贵州美食」同理。
- 根因：地理词典仅含城市名，不含省份（云南/贵州/新疆/海南）；这些省份命名的文档 `city_from_document_name` 返回 `None`，城市硬过滤失效。
- **修复**：`keyword_search.py` 新增 `PROVINCES` 省域集合与 `CITY_TO_PROVINCE` 城市→省份映射；硬过滤升级为**省域判定**（`region_from_document_name` + `parsed.region`），城市查询自动归省，省份查询可召回省内各城市文档。
- **复测通过**：`云南美食推荐`→仅云南、`贵州美食推荐`→仅贵州、`海南美食推荐`→仅海南、`三亚美食推荐`→仅海南（三亚归省）、`成都美食推荐`→仅四川、`青岛海鲜`→仅山东。新增 8 项省域单元测试。

**#2 [中] 城市文档薄弱或与查询弱相关时返回空结果**

- 复现：「成都」（裸城市名）与「成都亲子游」→ 0 结果。
- 根因：① 成都文档仅 1 个标题切片「成都旅游攻略飞书版本」，语义 top-15 未命中；② 严格城市过滤排除其他城市；③ 裸城市/弱词查询关键词无命中。
- 影响：用户输入城市名却得到「未找到匹配的已处理文档内容」，**提示有误导性**（该城市存在文档但无相关切片）。
- 处置建议：语义侧在城市查询时提高候选拉取量，或在城市文档存在但检索为空时返回降级提示「该城市暂无匹配内容」。

**#3 [低] 纯空白查询返回 200 而非 422**

- 复现：`{"query": "   ", "document_ids": []}` → HTTP 200，返回任意语义结果。
- 根因：`NonEmptyText` 仅校验长度（≥1），不校验空白。
- 影响：API 契约不一致（空串 422 / 空白 200）；前端已 `trim` 防护，风险有限。
- 处置建议：查询字段校验去除首尾空白后非空。

**#4 [信息] 数据质量问题**

- 成都旅游攻略.pdf 仅 1 个标题切片，几乎无检索价值，导致成都相关查询全部薄弱。
- 海南三亚旅游攻略.pdf 含目录/索引页切片（如页 2「焦点 Focus」），Chroma 返回的 top-N 中可能混入低信息量切片。

## 六、错误处理与安全

- 空查询/超长（>100）/`document_ids` 类型错误/坏 JSON → 均 422，错误信息结构化且不含内部细节。
- 响应扫描：未发现路径（`uploads/`/`extracted/`/`chroma/`/`documents.json`/`D:`）、密钥（`api_key`/`Bearer`/`sk-`）或供应商原始响应泄漏。（扫描中的 `\` 为 JSON 转义符，非泄漏。）
- Chroma 异常 → 503「知识检索服务暂不可用」，受控摘要。

## 八、迭代修复与新增（2026-08-23 下午）

### 1. RAG 检索秒回（解耦修复）

- **问题**：检索请求内联 DeepSeek 生成（5–8s），前端全程仅显示加载态，无任何结果。
- **修复**：检索默认不再触发生成（`generate_markdown` 默认 false）；结果区出现「生成完整回答」按钮，独立请求生成并弹窗展示；请求新增 `record_id`，生成按 id **更新同一条记录**而非重复创建；DeepSeek 超时提升至 60s（配置 `deepseek_timeout_seconds`）。
- **复测**：预热后检索 **63–74ms**；生成独立请求 7.4s（不阻塞检索）；记录不重复。

### 2. 查询记录展示与管理

- 面板仅展示**最新 3 条**记录；「管理记录 →」激活，打开管理弹窗查看**全部**记录（最新在前），可查看回答或删除。
- 新增端点：`GET /api/knowledge-records`（列表，已有）、`POST /api/knowledge-records/{id}/rating`、`GET /api/knowledge-stats`。

### 3. 赞/踩评价与真实统计

- 数据看板改为消费真实统计：三张统计卡、来源类型柱状图、按地区/按来源文档表格均实时反映评价。

## 九、迭代修复（2026-08-23 晚间）

### 1. 出行规划结果弹窗化

左侧出行规划表单结果改为**独立弹窗**展示（同 RAG 回答弹窗）：`#travel-mask`，提交后弹窗内显示处理进度，完成后填充 Markdown + 评价 + 元数据；不再跳转整页 `view-task`。

### 2. 住宿跨城市 POI 检索修复

- **根因**：route agent 将 `daily_areas[i].area` 设为高德地理编码的 `formatted_address`（如「四川省成都市」）；lodging agent 将其作为高德 POI 的 `region` 参数 → 高德无法映射单一城市 → `city_limit` 失效 → 返回全国酒店（长沙/呼伦贝尔/珠海）。
- **修复**：lodging agent 改用 `request.destination`（用户输入的城市名）作为 POI 检索区域；`recommended_area` 仍显示格式化区域。
- **复测**：成都行程 10 个酒店候选全部位于成都（凤凰山/太古里/武侯祠/春熙路等），跨城市泄漏消除。

### 3. RAG 检索无 Markdown 润色修复

- **根因**：此前的「解耦」使检索默认不触发生成（`generate_markdown` 默认 false），需手动点「生成完整回答」按钮，故用户检索后只见切片、无 Markdown。
- **修复**：前端在检索结果展示后**自动触发润色生成**（不阻塞秒回），完成后**自动弹窗展示**完整 Markdown；生成期间按钮显示进度，失败可手动重试；加入过期请求丢弃（新检索发起后旧生成的弹窗不会覆盖新结果）。
- **验证**：生成可靠性 3/3 成功（10–13s）；检索秒回 + 自动生成组合完整。
